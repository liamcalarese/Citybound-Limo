# Citybound Limo website

Live at **https://cityboundlimo.com**, hosted on GitHub Pages from the `main` branch. A push to `main` updates the live site within a couple of minutes.

The site is static and needs no build step. Each page is a folder with an `index.html` inside, so addresses are clean: `/fleet/`, `/blog/some-post/`, with no `.html`.

## Preview locally
Links start with `/`, so serve the site from this folder rather than opening files directly:

```
python3 -m http.server 8000   # then visit http://localhost:8000
```

## Structure
| Address | File |
|---|---|
| `/` | `index.html` |
| `/fleet/` | `fleet/index.html` |
| `/services/` | `services/index.html` |
| `/tours/` | `tours/index.html` |
| `/gallery/` | `gallery/index.html` |
| `/contact/` | `contact/index.html`, which embeds the Moovs booking page |
| `/blog/` and `/blog/<post>/` | `blog/`, generated by the blog build (see below) |
| any missing page | `404.html`, which also forwards old `.html` addresses to the new ones |

- `assets/css/styles.css`: all styles. Colors and fonts are variables at the top.
- `assets/js/main.js`: icons, mobile menu, fleet filter and photo switcher, gallery lightbox
- `assets/img/`: photos
- `content/blog/`: blog posts, written in Markdown
- `tools/build_blog.py`: builds the blog
- `CNAME`: the custom domain for GitHub Pages
- `.nojekyll`: tells GitHub Pages to serve the files as-is

## Booking / quotes
The Contact page embeds the Moovs booking page:
`https://customer.moovs.app/cityboundlimo/new/info?moovs_source=widget`.
Every "Get a Quote" button links to `/contact/#quote`.

## Blog
1. Copy `content/blog/_template.md` to a new file, such as `content/blog/2026-12-01-new-years-eve.md`. The part after the date becomes the address: `/blog/new-years-eve/`.
2. Fill in the title, date, description and photo at the top. Write the post below the second `---`.
3. Run `python3 tools/build_blog.py`.
4. Commit and push.

In posts, link to pages as `/fleet/` or `/contact/#quote`, and to photos as `/assets/img/photo.jpg`. Older-style links like `fleet.html` are converted automatically. Add `draft: true` to keep a post unpublished. Don't edit `blog/` by hand; the next build overwrites it.

## Editing the header or footer
Every page has its own copy of the header and footer. If you change them, update every page's `index.html` and `404.html`, then run `python3 tools/build_blog.py` so the blog picks up the change from the home page.
