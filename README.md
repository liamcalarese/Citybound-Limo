# Citybound Limo website

A static site that needs no build step. Open `index.html` in a browser, or serve the folder with any static host (Netlify, Vercel, GitHub Pages, Cloudflare Pages).

```
python3 -m http.server 8000   # then visit http://localhost:8000
```

## Structure
- `index.html`, `fleet.html`, `services.html`, `tours.html`, `gallery.html`, `contact.html`: the pages
- `blog.html` and `blog/`: generated by the blog build (see below)
- `content/blog/`: blog posts, written in Markdown
- `tools/build_blog.py`: builds the blog
- `assets/css/styles.css`: all styles. Colors and fonts are variables at the top.
- `assets/js/main.js`: icons, mobile menu, fleet filter and photo switcher, gallery lightbox
- `assets/img/`: optimized photos taken from the original site

## Booking / quotes
The Contact page embeds the Moovs booking page:
`https://customer.moovs.app/cityboundlimo/new/info?moovs_source=widget`.
Every "Get a Quote" button links to `contact.html#quote`, which scrolls to it. An "Open full screen" link opens the same page in a new tab.

## Blog
Posts are Markdown text files in `content/blog/`. To publish one:

1. Copy `content/blog/_template.md` to a new file, such as `content/blog/2026-12-01-new-years-eve.md`. The part after the date becomes the page address: `blog/new-years-eve.html`.
2. Fill in the title, date, description and photo at the top. Write the post below the second `---`. The template shows headings, bold, links, lists, quotes and images.
3. Run `python3 tools/build_blog.py`.
4. Upload or deploy the site as usual.

The build turns every post into a page in `blog/`, updates `blog.html` (newest first) and removes pages for deleted posts. Add `draft: true` to a post to keep it unpublished. Don't edit files in `blog/` or `blog.html` by hand; the next build overwrites them.

## Editing
The header and footer are repeated in every page. If you change them, update every page, then rerun `python3 tools/build_blog.py` so the blog pages pick up the change from `index.html`.
